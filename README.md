## 这是做什么的

洛奇 M 钓鱼助手读取右下角圆形按钮的画面，识别上钩、等待、指南针和骑马图标，再按 `Space`、`W`、`S` 完成收鱼、续钓或恢复。

图标默认使用图像模板匹配，由 ok-script 的 FeatureSet 提供。指南针是旋转动画，单独用中心黑点和指针配色做像素校正；其他图标不会自动回退到旧像素规则。“识别阈值”页保留可由用户手动选择的像素识别（旧版兼容）。

它先等待画面出现上钩图标，再根据所选模式判断收杆时机。模式 1 先确认绿条上方的中鱼图标，再追踪会随角色移动的头顶绿条；模式 2 使用自定义计时；模式 3 上钩后立即收杆。

## 功能

- **两种图标识别方案**：默认使用图像模板匹配；旧版像素识别只在用户手动选择时启用。
- **三种收鱼方式**：模式 1 通过中鱼图标定位动态绿条，并以槽中点灰→绿识别反弹，模式 2 固定计时，模式 3 上钩立即收杆。
- **耗材与背包保护**：连续尝试失败后，用 OK 特征确认鱼竿提示、背包满文字和红色背包图标，确认后停止监测。
- **背包清理（实验性）**：可在背包满时执行四类简单整理；默认关闭，并在整理前反复确认“大胆整理”已经关闭。
- **自动制作**：在“材料加工”中按分类选择木材、金属、布料或皮革，自动补队列、等待全部完成后领取；可指定加工次数或用完材料为止。“食物制作”仅预留入口，暂未开放。[使用方法](docs/automatic-crafting.md)。
- **跑鱼时间学习**：模式 1 检测到“讓牠跑掉了”后记录本轮耗时 `T`；提前量取 `T × 10%` 并限制在 1–2 秒，下一轮识别仍失败时按 `T − 提前量` 兜底收杆。正常识别到反弹时仍会立即收杆。
- **自动收鱼与续钓**：上钩后收鱼，图标恢复后再抛竿。
- **移动恢复**：停留过久出现失效指针时，可选择 `W → S` 往返恢复或仅按 `W` 向前恢复；仅 W 模式支持自定义次数与每次长按秒数。
- **骑马纠错**：检测到上马图标时不按 `Space`；检测到下马图标时只尝试一次下马。
- **后台运行（推荐）**：默认优先识别标题为“瑪奇 Mobile”的窗口；找不到时可手动选择。使用 Windows Graphics Capture（WGC）获取画面，并通过窗口消息（PostMessage）发送输入，不会把按键发送给当前前台程序。
- **界面与排查工具**：支持日间/夜间主题、识别区域快照、本地错误日志和诊断包。
- **后台悬浮栏**：助手最小化后查看校准、运行状态，点击等宽的暂停/继续按钮控制当前任务；可在设置里关闭或调背景透明度。背包清理中暂停会安全停止，不自动续点。
- **语音提醒**：可选择人物音色，播报校准、监测、识别异常、窗口状态和背包整理结果；不需要时可在设置中关闭。
- **更新检查**：在“设置 → 更新与关于”手动检查 GitHub Release，也可选择启动后检查。

界面入口：钓鱼设置按“收鱼策略 / 自动续钓 / 背包清理”分类；语音和悬浮栏在“设置 → 常规”，日志导出在“设置 → 诊断”，背包测试在“设置 → 调试”。控制台的显示器和分辨率选项可在“画面配置”中展开。

## 使用前说明

> [!CAUTION]
> 本工具仅识别现有游戏画面并模拟按键，不读取游戏内存、不修改游戏文件。请自行确认目标游戏的规则，并自行承担使用风险。

并非所有渲染和输入环境都支持后台运行。洛奇 M 必须保持打开且不可最小化；如果窗口画面正常但按键没有反应，可尝试“前台运行”，回到游戏后重新校准。前台运行必须保持游戏位于前台，避免操作到其他程序。

## 下载与运行

### 直接运行

在 [Releases](https://github.com/fanqiejiu/Mabinogi-M-Fishing-Assistant/releases) 下载带版本号的 `ok-MabinogiFishing-vX.Y.Z.exe`，解压后直接运行。首次启动会请求管理员权限；程序已运行时再次启动会给出提示并退出。

首次启动会短暂显示项目图标和版本号。配置、日志和诊断包均保存在本机。

### 源码运行

```powershell
git clone https://github.com/fanqiejiu/Mabinogi-M-Fishing-Assistant.git
cd Mabinogi-M-Fishing-Assistant
.\setup.bat
.\run.bat
```

系统要求：Windows 10/11、Python >= 3.12（仅源码运行或自行打包需要）。

## 快速开始

1. 进入游戏钓鱼场景，先卸下宠物，并确保右下角圆形按钮完整可见。
2. 在“控制台”确认游戏窗口；需手动调整显示器、画面模式和分辨率时，展开“画面配置”。
3. 在“识别阈值”确认识别方式；推荐保留默认的“图像模板匹配（推荐）”。
4. 默认选择“后台运行（推荐）”，捕获方式为 Windows Graphics Capture。确认目标窗口是“瑪奇 Mobile”，再把鼠标放到圆形按钮中心，直接按 `F7`。
5. 按 `F9` 保存识别区域和完整诊断；完整画面只保存在本机，发送前请确认其中没有不想分享的内容。
6. 点击“开始监测”或按 `F8`。

捕获方式只决定如何获取画面：Windows Graphics Capture（WGC）为默认选项，PrintWindow 为手动选择的兼容选项。两者均使用 PostMessage 输入；切换捕获方式不会改变图标识别算法，也不能解决所有按键无响应问题。自动制作固定使用 WGC 与 PostMessage，不受钓鱼窗口捕获选项影响。

| 快捷键 | 作用 |
| --- | --- |
| `F7` | 校准钓鱼按钮中心 |
| `F8` | 开始钓鱼 / 停止当前任务 |
| `F9` | 保存识别区域与完整诊断包 |
| `Esc` | 紧急停止 |

### F9 怎么用

F9 是保存识别现场，不是开始钓鱼，也不会重新校准。图标明明出现却没反应、体力条不触发时，保留当时的画面按一次 F9；先完成 F7 校准即可，不必启动监测。

保存会在后台处理，不占用界面和快捷键监听线程。控制台会显示保存结果，点“查看截图”检查圆形按钮是否完整，点“打开诊断目录”找到文件。保存期间再按 F9 不会重复排队。

每次保存的文件带时间，不覆盖上一次，位置在 `%LOCALAPPDATA%\MabinogiFishingHelper\vision-diagnostics\`。ZIP 中有：

- `roi.png`：钓鱼按钮的识别区域。
- `frame.png`：同一时刻的完整画面。
- `report.json`：分辨率、校准位置、识别配置和分层检查结果。

前台模式请回到游戏再按 F9，否则可能截到其他程序；后台模式只截选定窗口，游戏不能最小化。文件不会自动上传，分享前请检查角色名、聊天和其他私人内容。

## 常见情况

| 情况 | 处理方式 |
| --- | --- |
| 图像模板匹配漏掉上钩 | 用 `F9` 检查圆形按钮是否完整，并保留逐层识别报告；重新校准。仍不兼容时可手动改用旧版像素识别。 |
| 旧像素模式漏掉上钩 | 适当降低鱼体阈值，例如 `1000 px`。 |
| 旧像素模式把普通抛竿当成上钩 | 提高鱼体阈值，例如 `1450 px`。 |
| 识别区域不完整 | 调大识别区域后重新校准，再用 `F9` 检查快照。 |
| 切到浏览器后没有继续 | 确认选择“后台运行”且游戏未最小化，用 `F9` 检查画面；画面正常而按键无响应时可尝试前台运行，并重新校准。 |
| 界面显示监测中但没有动作 | 查看运行日志或导出诊断包；重试达到上限后会停止任务。 |

## 数据与日志

- 钓鱼配置保存在项目目录的 `fishing_config.json`。
- 错误日志和诊断 ZIP 位于 `%LOCALAPPDATA%\MabinogiFishingHelper\`；连续 20 秒无法识别状态时会自动保存现场，每次监测最多 3 份。
- 硬件型号只在启动时读取一次，用于诊断；不会持续监测。
- 不会自动上传日志或诊断包。完整识别诊断可能包含角色名或聊天内容，发送前请自行确认。
- 更新检查仅在手动触发或启用启动检查后访问 GitHub Latest Release API。
